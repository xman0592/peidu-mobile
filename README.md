# 陪读 · 手机语音问答

八上期中三科（地理 / 生物 / 历史）的语音陪读网页，手机上打开即用。

## 用法

1. 安卓手机用 **Edge** 或 **Chrome** 打开：https://xman0592.github.io/peidu-mobile/
2. 「添加到主屏幕」，像 App 一样用。
3. 选科目 → 开始本轮 → 系统念题 → 点「开始回答」说话 → 自动判分。
4. 判分是关键词匹配，偶尔不准，结果页可以手动改判。

## 说明

- 语音识别依赖浏览器和网络；如果提示不可用，点题目下方的输入框，用键盘上的麦克风键说话。
- 学情存在手机浏览器本地（localStorage），换手机/清缓存会丢。
- 考试日期显示在右上角。

## 更新考点

1. 改 `陪读/大纲/*.json`（电脑端）。
2. 改 `peidu-mobile/keys.json` 里对应考点的关键词。
3. 运行 `python peidu-mobile/build_data.py` 重新生成 `data.js`。
4. 推送仓库，Pages 自动更新。

文件：`index.html` 页面、`app.js` 逻辑、`data.js` 数据（生成）、`keys.json` 关键词（手写）。
